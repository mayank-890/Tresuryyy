# Trading System

Automated trading system for Indian derivatives, commodities, and Delta Exchange crypto derivatives. The engine is C++20. Research, services, and tooling are Python 3.12. The UI is static HTML, CSS, and JavaScript. The system moves real money once live, so correctness and safety take precedence over speed and features.
